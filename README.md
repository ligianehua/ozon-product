# ozon-product

Ozon 商品资料与俄语本地化素材。

## 固定规则

1. 商品整理使用 `ru-ozon-product-listing` Skill 工作流；核对事实、俄语本地化、成本、物流及待确认项。
2. 每个产品使用独立的产品名称文件夹，原图、俄语素材、表格与核对说明放在对应文件夹中。
3. 每次更新都更新本 README，记录日期、改动内容和未完成事项。

## 产品

- [剃须刀](剃须刀/README.md)：8 张俄语功能、尺寸和套餐图片。
- [lamp stand](lamp%20stand/README.md)：B 款黑色、银色、金色三张俄语尺寸图片。
- [Mobile Stand](Mobile%20Stand/README.md)：手机、平板及笔记本支架资料；42 张图片、俄语参数与成本计算表。
